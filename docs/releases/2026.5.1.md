block in folder view and moved its filter, sort, grid/list, search and New

and Labs and the Advanced forms pick local paths with a Browse button.

## How it was built

```bash
python scripts/release_x8_local.py --version 2026.5.1 --dry-run   # build, sign, assemble
# commit the version bump so the tag and the tree agree
tok=$(printf "protocol=https\nhost=github.com\n\n" | git credential fill | sed -n 's/^password=//p')
GH_TOKEN="$tok" python scripts/release_x8_local.py --version 2026.5.1 --skip-build \
  --notes-file /tmp/x8-notes-2026.5.1.txt
```

The build compiles each flavor separately (`UNSLOTH_DESKTOP_FLAVOR` is a
compile-time value), signs each with `studio/src-tauri/x8-updater.key` (not in
the repository), and stages the pairs in `release-out/` under their published
names before anything is uploaded.

One commit landed after the build started: `7ee8db33c` restores `en.ts`'s
original line wrapping, which the pages pass had reformatted wholesale, and
keeps only the eleven entries whose copy actually changed. It moves no string —
values are byte-for-byte what the binaries were built from — so no rebuild was
needed and the tagged tree is the one that ships.
