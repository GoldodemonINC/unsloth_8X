## What shipped

### Pre-flight dataset check

`studio/backend/core/training/dataset_preflight.py` walks the rows a run would
read — JSONL, JSON, CSV or Parquet, one file or a folder — and reports the
defects that stop training: unparseable rows with their line numbers, rows with
no recognisable text field, exact duplicates, and sequences longer than the
tokenizer will keep. It is read-only by design; a check that silently repaired a
row would make the run manifest disagree with the file on disk.

The Studio dataset panel gains a card that runs it for the selected local upload
and shows the counts, the detected text field, and the first few offending rows.
The route is `POST /api/train/dataset/preflight`, bounded to 200,000 rows by
default. Duplicates and overlong rows are warnings; only unreadable rows block.

### Loss anomaly detection

`studio/frontend/src/features/training/lib/loss-anomaly.ts` turns the loss curve
into one finding: a non-finite value, a divergence (the last third is more than
25% above the first third and rising), a spike (2.5× the previous 20-point median
and at least +0.5), or a plateau (a flat last quarter above 0.1). The chart
section renders it as a callout with the step and the change to try. The rules
stay quiet on early-run noise and on a curve that has already converged.

### Run lineage

A new Labs experiment (`lineage`, on by default like the other Labs tabs) builds
the family tree from the `run_manifest.json` every stage already writes. The
backend matches recorded input paths against the folders that own a manifest, so
an edge means a real parent, not a shared folder name; a Hub id produces no
edge. The tab draws roots first and keeps the rest under "Not linked to a root"
rather than hiding them.

### Deploy scripts

Export now has a Deploy scripts card for the selected source. It generates an
Ollama Modelfile (`FROM`, `num_ctx`) or a `vllm serve` command with served name,
context length, port and optional tensor parallel, and copies it. Checkpoint
mode resolves the checkpoint's display name to its folder before building the
script. Nothing runs from the card.

### Polish

- Labs loading uses skeleton cards and tabs instead of a spinner line.
- Artifact rows lift a pixel on hover (motion-safe) and return on press.
- Route transitions ease over 160 ms instead of snapping in 60 ms.

## What this release does not include

The rest of #13–#18: system tray, webhooks, cron/scheduled jobs, batch queue,
HF push-to-publish, compliance mode, TIES/DARE/SLERP merge sliders, the visual
pipeline node editor, and the A/B prompt comparator. #18 ("Polish the NRC-2
License") was left untouched: rewording a licence needs the maintainer's own
language, not a guess.

The new UI was typechecked and bundled, and its logic is covered by the tests
above, but it was not clicked through in a running desktop build. The pre-flight
card is limited to local uploads by design; a Hub dataset needs to be downloaded
before it can be scanned, and the card does not offer that yet.
